Binggo

不用一个个找活动，也不用一个个点参加。

本机运行的 B 站抽奖助手 · 数据保存在你的电脑上

免费下载（Windows / Mac） GitHub 开源

为什么用它

自动发现

从 UP 合集和监控用户动态里收集抽奖，不用自己到处翻。

一键参加

互动、转发、预约都能一键操作，还支持三连一次清多条。

数据本机

登录信息只存在你的电脑里，软件只在本机打开，不上传云端。

可定时

控制台里可设置定时更新与参与，电脑开着就能自动跑。

三步开始

  1. 下载安装包，双击安装（Mac 用户拖到「应用程序」）
  2. 打开软件，用手机哔哩哔哩扫码登录
  3. 在「数据源」点「更新此源」，再到「活动」里参与抽奖

常见问题

需要会编程吗？

不需要。下载安装包，像装普通软件一样使用即可。

安全吗？会不会偷账号？

Binggo 是开源软件，数据存在本机。不会把 Cookie 上传到作者服务器。

打开后活动列表是空的？

新安装需要先登录，再在「数据源」里点「更新此源」拉取活动。

能保证中奖吗？

不能。它只是帮你省去找活动和重复点击的时间。
