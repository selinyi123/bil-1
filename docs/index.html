常见问题

使用前，你可能想问

需要会编程吗？

不需要。下载安装包，双击安装，扫码就能用。

安全吗？Cookie 会上传吗？

凭证只存在本机。控制台绑定 127.0.0.1，不会上传到作者服务器。代码开源可审。

为什么活动列表是空的？

新安装需先登录，再在「数据源」对 UP 合集点「更新此源」拉取活动。

一定要配置 LLM 吗？

只有转发抽奖需要。互动与预约可直接参与。

能保证中奖吗？

不能。Binggo 只帮你省去找活动和重复点击的时间。
