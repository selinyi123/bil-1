常见问题

需要会编程吗？

不需要。下载安装包即可。

Cookie 会上传吗？

不会。只存本机，控制台仅 127.0.0.1。

活动列表为什么是空的？

先登录，再在数据源点「更新此源」。

一定要配 LLM 吗？

仅转发抽奖需要；互动 / 预约可直接参与。

能保证中奖吗？

不能。Binggo 只帮你少找、少点。
