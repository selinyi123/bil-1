## 0. 总前提（已对齐）

| 前提 | 含义 |
|------|------|
| **设计零改动（用户硬性）** | 现网前端页面的**所有设计**不得改变：布局、视觉、HTML 结构/id/class、文案骨架、交互形态均冻结 |
| 行为可感知不倒退 | 任务/SSE/调度/设置等功能路径与现网一致；本方向只做工程化拆分与构建 |
| 后端契约已稳 | 方向四错误码 / REST / SSE 协议冻结 |
| 本地单机控制台 | 仍由 FastAPI 托管静态资源 |
| 打包可衔接 | `packaging/windows` 须纳入前端 build |

## 1. 拍板结论一览（已定）

| 编号 | 议题 | 结论 | 说明 |
|------|------|------|------|
| **A** | 技术栈 | **A1** | Vite + TypeScript；**无** Vue/React |
| **B** | 迁移策略 | **B2** | 源码进 `web/frontend/`；运行时只服务构建产物 |
| **C** | UI 改写范围 | **C1 + 设计零改动** | HTML/CSS/视觉/结构**全部冻结**；仅 JS 逻辑模块化 |
| **D** | 产物与托管 | **D2** | 构建输出 `web/static/dist/` |
| **E** | 开发联调 | **E1** | Vite dev + proxy 后端（含 SSE） |
| **F** | TS 严格度 | **F2** | `strict`；边界类型渐进 |
| **G** | 状态管理 | **G1** | 轻量 `state`；无 store 库 |
| **H** | CSS | **H1** | `styles.css` **原样**纳入构建，禁止重写/拆视觉 |
| **I** | 打包衔接 | **I2** | windows/CI 强制先 `npm run build` |
| **J** | 前端测试 | **J1** | 少量 vitest；E2E 归方向六 |
| **K** | SSE/实时 | **K1** | 独立模块；协议不变 |

### 边角（已定）

| 编号 | 议题 | 结论 |
|------|------|------|
| **①** | dist 是否提交 git | **不提交** |
| **②** | Node | **20 LTS** |
| **③** | 包管理器 | **npm** |
| **④** | 旧 `app.js` | 验收后 **归档/删除**，禁止双入口 |
| **⑤** | OpenAPI 生成客户端 | **v1 不做** |
| **⑥** | 路径别名 | `@/` → `src/`（默认可做） |
