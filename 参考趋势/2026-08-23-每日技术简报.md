## 3. 技术趋势与架构参考

### Agent Control Surface 正从 Chat 变成 Goal/Run 管理

```text
Goal
├ tasks
├ agent/worker
├ budget
├ policy
├ run states
├ cost
└ evidence
```

### Credential 权限进入 Egress Policy

```text
CredentialGrant
├ principal
├ credential_ref
├ destination_hosts[]
├ scope
├ expires_at
└ approval
```

对于自动化账号系统，这比“环境变量里有 Cookie”更接近长期安全边界。

### AI UI 需要 Contract Validator

```text
Design Contract → Generate → Real UI → Interaction Test → Validator → Evidence
```

Binggo 当前原生 DOM/Vite UI 可以先做轻量 validator，而无需换框架。

## 4. 对五个项目的机会、风险和行动建议

### DPMS
保持幂等执行、状态回读、Evidence 与 real-run gate；增加 Goal/Budget 只读管理面，但不产生第二套 side-effect authority。优先 `CredentialGrant v0.1`。

### Prompt Performance Engine
做 Context Topology Ablation，并加入未授权 destination 的 policy benchmark，验证 fail-closed 是系统事实而非模型行为。

### KIS
增加 `ContextBundle/ContextSelection`，记录 exact revision、trust state、selection reason 与 token budget。

### ClipVault
不扩功能；未来 OTP/secret 传输绑定 destination_device / destination_app / TTL / one-shot / persistence=forbidden。

### Binggo
当前已有 FastAPI、本地 Web UI、job state machine、scheduler、多账号池和 MCP，是五个项目里最适合快速验证小型 Agent Control Surface 的地方。

建议第一版新增：

```text
Goal
├ title
├ time_window
├ max_actions
├ allowed_accounts[]
├ risk_limit
└ run_refs[]
```

以及 MCP 只读/预览工具：

```text
inspect_goal
inspect_run
explain_failure
preview_action_plan
inspect_budget
```

执行链保持：

```text
Agent understand/explain
      ↓
Action Preview
      ↓
Existing policy / user gate
      ↓
Existing deterministic executor
      ↓
API readback + evidence
```

暂时不要增加“LLM 直接点赞/关注/转发/评论”的通用 tool。

第二个值得做的是账号 CredentialGrant：Cookie/credential 只允许发往既定 Bilibili API host，限制 task scope 与 TTL；代理、OCR、LLM 凭据分别独立，避免一个 Agent session 获得全部 secret。

## 今日行动优先级

1. Binggo：先设计 `Goal + Budget + RunRef`，只读展示现有任务状态。
2. Binggo MCP：增加 `inspect_run / explain_failure / preview_action_plan`，不要新增直接 side-effect tool。
3. DPMS：`CredentialGrant v0.1`。
4. PPE：Context Topology Ablation。
5. KIS：ContextSelection artifact；ClipVault 只更新 secret destination policy。

## 最终判断

Binggo 最适合承担的是“Agent Control Surface 实验场”，不是“把确定性自动化改写成 LLM 自动化”。

今天跨项目最值得新增的 primitive 是 `CredentialGrant`：账号系统尤其应把 credential 使用权绑定 destination、scope、TTL 和 approval。共享 primitive 建议维持：`ExecutionRecord / ContextSelection / CostProfile / PolicyDecision / TrustContext / CredentialGrant / Evidence`。
